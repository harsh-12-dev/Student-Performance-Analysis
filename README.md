# Student Performance Analysis

## Overview

This project analyzes student performance data using Python and explores academic performance, study time, and gender-wise differences in final grades.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Dataset exploration and cleaning
- Missing value analysis
- Duplicate detection
- Average final grade calculation
- Students scoring above 15
- Study time and final grade correlation
- Gender-wise average performance
- Data visualization

## Visualizations

- Distribution of Final Grades
- Study Time vs Final Grade
- Average Final Grade by Gender

## Dataset

The analysis uses the Student Performance dataset (`student-mat.csv`).
